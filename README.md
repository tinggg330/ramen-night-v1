# 深夜泡面小游戏 V1

React + TypeScript + Vite 实现的手机竖屏互动原型。

## 已完成

- 3 种汤底、3 种面、6 种配菜（最多选 3 种）
- 6 步泡面制作流程
- 独立的金黄方便面、白色乌冬、绿色菠菜面透明素材，选择页与碗内同步
- 按汤底变化的料包倾倒与颗粒落下动画（不融化），加水后显示汤
- 配菜按选择数量分配份量，芝士铺面加大
- 20 秒等待，可点击杯盖加速
- 三种熟面各有满碗、约七成、约四成、少量残留四张透明插画，共 12 张；吃面时逐步露出汤，面条不整体缩小，配菜同步减少
- 揭盖、7 口吃面、3 口喝汤、空碗完成页
- 卧室背景音循环播放、静音记忆
- 设置、玩法介绍、晚安模式
- 320px 与 390px 手机宽度适配

## 本地启动

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm run lint
```

## 素材

运行时素材放在 `public/assets/`。独立素材母包位于相邻目录 `../ramen-night-assets/`。

当前只正式接入 `bedroom-ambient-loop-01.m4a`。嗦面、喝汤、揭盖和碰杯音效的触发位置会在相应交互动作中继续补齐。

视觉规范见 `DESIGN_SYSTEM.md`，对照确认稿的校对记录见 `FIDELITY_LEDGER.md`。

### 制作互动音效

`public/assets/audio/interaction/` 接入撕盖、放面、撒调料、倒水四个原始音效。两次撕盖共用撕盖声；放面延迟 0.5 秒对齐落下，撒调料延迟 0.2 秒后播放约 2 秒并淡出，倒水延迟 0.44 秒后短循环至水流结束。原始音频不裁改，缩短通过播放时限实现。互动音量为 0.36（放面 0.42），统一受声音开关控制。
